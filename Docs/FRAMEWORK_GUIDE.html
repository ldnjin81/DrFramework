새 액션 RPG를 위한
게임 프레임워크 설계

언리얼 엔진으로 3인칭 근접 액션 RPG를 새로 시작할 때 게임 코드를 어떻게 나누고 서로 어떻게 맞물리게 할지 정리한 참고 설계다. 클래스 이름의 Xx는 프로젝트 접두사 자리다. 표의 수치는 처음 잡을 때 쓰는 권장 시작값이다.

3층수명별 소유 구조
16게임 시스템
3기본 데이터 테이블
C++ 우선BP는 표현만
시간은 틱으로 잰다타격 구간·패턴·경직은 물론 효과 지속·쿨다운도 틱 누적으로 잰다. 타이머는 HUD 연출에만 쓴다. 테스트가 매번 같다.
표현이 없어도 규칙은 돈다모션·FX가 없으면 대체 경로로 움직인다. 화면 없는 테스트도 통과한다.
수치는 데이터, 규칙은 코드밸런스는 엑셀 테이블과 데이터 에셋에서 바꾼다.
이벤트로 잇는다속성 변화가 캐릭터·HUD·소리·엔카운터로 퍼진다. 화면이 규칙을 바꾸지 않는다.

전체 구조

무엇이 얼마나 오래 사는지로 나눈다

피해 계산

한 번의 타격이 생명력이 되기까지

UXxGameplayEffect_Damage → UXxAttributeSet::PostGameplayEffectExecute

공격자는 ApplyDamage(대상, 피해, 포이즈 피해)로 C++로 정의한 즉시형 피해 효과를 보낸다. 값은 메타 속성에 담기고, 받는 쪽 속성 세트가 아래 순서로 처리한다.

  1. 이미 죽었으면 무시사망 이벤트가 두 번 나지 않게 한다.
  2. 무적이면 전부 막음회피 중 무적 구간(State.Invulnerable).
  3. 정면 공격 + 쳐내기 중피해 0. 공격자의 포이즈를 40 깎는다. 보스가 그로기에 빠지는 주된 길이다.
  4. 정면 공격 + 막기 중원래 피해의 50%만큼 기력을 쓰고 피해를 30%로 줄인다. 기력이 모자라면 막기가 깨져 전액 피해와 경직.
  5. 방어력 경감max(피해 − 방어력, 피해 × 5%). 아무리 단단해도 5%는 들어간다.
  6. 효과 배율과 보호막활성 효과들의 "받는 피해" 배율을 곱하고, 보호막이 있으면 먼저 흡수한다.
  7. 반영과 알림기력 회복을 1.5초 멈춘다. 생명력을 줄이고 피격 소리, 피해 이벤트를 보낸다. 0이 되는 순간에만 사망을 알린다.

포이즈 피해

무적이거나, 정면 공격을 쳐내기·막기로 받는 중이면 포이즈가 깎이지 않는다. 0 이하가 되면 최대치로 다시 채우고 포이즈 붕괴를 알린다. 플레이어는 0.8초 경직, 보스는 2.67초 그로기다.

상태 효과

한시 효과

효과마다 남은 시간과 주기 위상을 ASC가 틱에서 줄인다. 다시 걸리면 남은 시간만 새로 시작하고 주기 위상은 이어 간다. 주기 피해(화상·출혈 등)는 만료 시각까지 주기마다 들어간다.

상시 효과

장비처럼 붙어 있는 동안 계속된다. 시간 없이 더하고 뺀다. 같은 태그의 한시 효과와 따로 관리한다.

배율

이동 속도, 받는 피해, 주는 피해 배율을 모든 활성 효과에서 곱해 쓴다. 효과가 없으면 1이다.

즉발

걸리는 순간 현재 생명력 비율 피해, 포이즈 피해를 한 번 준다. 보호막은 크기만큼 피해를 흡수한다.

중첩 규칙

  • Refresh: 다시 걸리면 지속 시간만 새로 시작한다.
  • Accumulate: 단계가 쌓이고, 단계마다 테이블의 보너스(%)가 주 수치에 붙는다.

데이터만으로 기술을 만들 때는 UXxGameplayAbility_ApplyEffect를 쓴다. 이벤트로 받은 대상에게 지정한 효과 Id를 건다.

  • 표시 메시가 있으면 8방향 구르기 모션 중 하나를 고른다(앞부터 시계 방향 45도 간격). 원본 1.17초를 1.6배 속도로 재생하고, 모션이 캡슐을 끌고 간다.
  • 표시 메시가 없으면(화면 없는 테스트) 0.35초 동안 450cm 대시한다.

막기와 쳐내기

누르면 처음 0.3초는 쳐내기(State.Parrying), 이후 1.13초까지 막기(State.Guarding)다. 어빌리티는 태그만 켜고, 실제 경감은 속성 세트가 피해 계산에서 처리한다.

동작 상세

같은 손맛을 내려면 맞춰야 하는 계산

일정 속도 이동

루트 모션 소스(ConstantForce)를 덮어쓰기 모드·우선순위 5로 건다. 힘 = 방향 × 거리 ÷ 시간, 끝 속도는 제한(보스 돌진은 0).

모션 따라가기

매 틱 골반 뼈의 메시 공간 수평 위치를 샘플링해 직전 값과의 차이만큼 캡슐을 옮긴다. 벽에 막히면 미끄러지고, 메시는 그만큼 반대로 밀어 캡슐 위에 둔다.

락온 대상 고르기

거리·시야각·화면·가시 조건을 통과한 후보 중 |요 차이| + 거리×0.001이 가장 작은 것. 전환은 그 방향으로 1도 넘게 떨어진 후보만.

락온 카메라

시선과 몸을 대상 쪽으로 속도 7로 보간, 피치 −8 바이어스(−35~10). 가까울수록(350 안) 암을 최대 +150 늘리고 측면 오프셋 70을 줄인다.

보스 회전

초당 180도까지 고정 속도로 돈다. 정면은 전방과 대상 방향 사이가 60도 이내.

타격감

공격자와 피격자 모두 시간 0.08배로 멈춘다(겹치면 긴 쪽). 피격자 메시에 오버레이 0.1초. 화면 흔들림은 보스 공격이면 맞은 쪽, 아니면 때린 쪽. 내려찍기는 1500 안에서 거리만큼 약해진다.

오디오

원거리 소리 16~24초마다 1800~3200 반경, 보스 발소리 0.65초 간격(속도 > 80). 교전 시 음악 2초 페이드인, 사망 시 0.3으로 줄임, 승리 3초 페이드아웃. 체력 30% 이하에서 큰 피해면 큰 신음.

HUD

1920 기준 왼쪽 위 플레이어 패널(체력 12px·기력 8px 게이지), 아래 가운데 보스 패널(800 폭). 게이지 머티리얼은 채움 비율과 잔상 비율을 따로 받는다.
